# Nishant — Portfolio

Personal portfolio of Nishant, a CSE (AI & ML) student at VIT Chennai (2027).

A single static page (`index.html`) with no build step. Prompts for the site were dictated with Wispr Flow.

## Run locally
Open `index.html` in a browser.

## Update details
Edit the `CONFIG` block near the bottom of `index.html`:
- `email` — contact email shown in the Contact section
- `resumeUrl` — public link to your resume
- `counts` — verified prompt and keystroke counts for the Built by Voice section

Project repo links live in the `PROJECTS` array (`repo` field).

## Deploy
Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
